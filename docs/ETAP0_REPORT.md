## Что не сделано и почему

- Реальные цифры МРОТ, региональные минимумы и ссылки на части/пункты методички не добавлены: нет проверенных данных Эрики. Учебные числа явно отмечены как демонстрационные.
- Уровни 1, 2, 4, финальная ведомость/акт и награда за все уровни не реализованы: находятся вне этапа 0.
- Реальный деплой и запуск GitHub Actions не выполнялись по запрету публикации. Workflow проверен статически и локальной проверкой base, но не запуском на GitHub.
- Эталонные тесты по методичке v5 ещё невозможны: фикстура пуста. Текущие тесты проверяют контракт ТЗ и вымышленные числа.
- Полная музыкальная композиция не добавлена: реализован тихий собственный синтезированный фон. Сторонние звуковые ресурсы не требуются.
