# ТЗ v1: онлайн-тренажёр «Инспектор труда: Дело о минимальной зарплате»
Проект МРОТ (п. 6.3 методички), Марданшин А. В., гр. 44-72. Согласовано с Артёмом 17.11.2026. Исходная концепция GPT пересказана в чате Артёма (17.11); первый вариант GPT с формами (отклонён) — /workspace/mrot_trainer/GPT_formy_variant_otkloneno.txt.

## Суть
Одна веб-страница (ссылка + QR в методичке). Игрок — начинающий специалист отдела проверки зарплаты: проверяет расчёты минимальной оплаты труда, находит ошибки, открывает более сложные дела. В конце «Акт проверки».

## Уровни (≈15–18 мин)
1. Машина времени (~2 мин): история МРОТ и ПМ с 1991 г. — «выше/ниже», расставить события на шкале. ТОЛЬКО реальные данные из методички (Эрика выпишет из v5).
2. Карта минимумов (~2 мин): 10 реальных регионов из части 3 методички, цифры только из методички; сравнить, где применимый минимум выше, открыть регион.
3. Карточки работников (~5 мин): вымышленные работники/компании/учебные регионы («Северный край» и т. п.), случайные зарплата, база, k, s. Решить: нарушение есть/нет, посчитать недоплату.
4. Аудит ведомости (~4 мин): чужой расчёт с подложенной ошибкой (не та база; k и s сложены/применены неверно; арифметика; округление) — найти и выбрать объяснение.
Финал «Дело № 001» (~4 мин): одна цельная ведомость на 3–4 работника (не повтор шагов уровней), итог — вывод о нарушении и сумма недоплаты → «Акт проверки».

## Правила расчёта
Применимый минимум = B × (k + s), B — МРОТ или региональный минимум (если он выше и применим). Не придумывать других правил; детали и округление — по методичке v5 (уточнит Эрика).
Реальные регионы никогда не сочетать с выдуманными коэффициентами; генерация — только для учебных вымышленных регионов.

## Обратная связь
Ошибка → короткая подсказка; повторная ошибка → пошаговый разбор + «Повторить: часть N, п. X методички». Ответ не раскрывается сам.

## Награды
XP: с первой попытки +100; после ошибки (самостоятельно) +70; после подсказки +50; серия 3 без ошибок +50; все уровни +150. Без штрафов, скорость не в основном зачёте.
Звания: Стажёр → Младший инспектор → Специалист по расчётам → Главный аудитор. Достижения: «Историк МРОТ», «Региональный эксперт», «Идеальный расчёт».
Фишки: ≤1 «Срочная проверка» за игру; «Личное дело» с темами к повторению; «Повторное расследование» с новыми данными.
Не делать: рейтинг группы, отчёт преподавателю на сервер, внутреннюю валюту.

## Стиль (важно для Артёма)
Стильно и «по-взрослому», не детская игра: деловая эстетика расследования — папки дел, документы, штампы «Проверка завершена», архив, карта. Красивые ассеты (можно генерировать через Codex/ИИ), аккуратные анимации переходов, звуки/фоновая музыка ненавязчиво с выключателем. Весь интерфейс на русском, работает с телефона и проектора.
