# Этап 2. «Дело № 001» и «Акт проверки»

Финал открывается в «Архиве дел» после завершения уровней 3 и 4. Игрок выбирает общую базу для вымышленной мастерской, отмечает нарушения в четырёх строках, вводит недоплаты, сумму по организации и общий вывод. На телефоне те же четыре строки показаны карточками внутри одного документа. Используется прежняя формула B × (k + s), а недоплата равна положительной разности между минимумом и зарплатой.

Ведомость проверяется целиком по кнопке «Подписать акт». Ошибка в базе подсвечивает только выбор базы. При верной базе отдельные ячейки получают подсказки, а после повторной попытки можно открыть сравнение «В ведомости / Верно». Текст для повторения нейтрален на всех игровых экранах. Надбавка отображается в едином формате «20 % (0,20)».

Подписанный акт фиксирует дату устройства, расчёт и результаты игры на момент подписи. Имя необязательно. Оно сохраняется в localStorage вместе с черновиком и актом. Сводка считает зачтённые с первой попытки карточки и ведомости текущих прохождений и сам финал, если он принят с первого раза. Финал даёт 100, 70 или 50 XP. За все доступные уровни один раз начисляется ещё 150 XP. Список уровней для бонуса находится в **src/config.ts**.

Для повторной съёмки выполните сборку, задайте в PowerShell **$env:FINAL_SCREEN_ROOT = 'docs/screens/etap2'** и запустите **npm run test:browser**. Полные отчёты Lighthouse после **npm run audit** сохраняются в **work/etap2/lighthouse/**.
