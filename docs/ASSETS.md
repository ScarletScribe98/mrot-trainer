# Ассеты «Зелёной лампы», этап 0.6

Созданы для проекта 17 ноября 2026 года. Все изображения — оригинальные SVG/CSS. Скачанных изображений, фотографий, узнаваемых реальных людей и чужих логотипов нет. Растровая генерация не применялась, промты изображений не использовались. Сторонние лицензии на новые рисунки не требуются. Шрифты остаются локальными OFL; см. CREDITS.md.

## Гравюрная пластина

`public/assets/archive.svg` — 20 исходных символов с обновлёнными шестью портретами и пятью иконками уровней. Портреты также сохранены отдельными файлами `portrait-1.svg` … `portrait-6.svg`. `grain.svg` — лёгкое печатное зерно. Прежние простые символы лампы/стола в пластине не используются в новой сцене; их заменила подробная многослойная графика.

Профили вымышлены: Вера — блуза и канцелярские принадлежности; Марк — рабочая куртка и инструменты; Алина — очки и измерительная принадлежность; Роман — борода, рубашка и связка ключей; Нина — каре, платок и гарнитура; шестой старший сотрудник — очки, седые пряди и пиджак. Боковой свет, штрихи волос/кожи/ткани, морщины и складки нарисованы отдельно. Все шесть видны в фотокаталоге «Об игре».

Иконки уровней: раскрытая книга, складная карта с условными контурами, стопка кадровых карточек, ведомость с карандашом, итоговый документ с отметкой. Применены тонкие двойные линии, тени штриховкой и мелкие детали без официальных гербов.

Штампы — три оригинальные фактурные рамки с маской потерь краски; надписи остаются HTML. Бумага получила волокна, загнутый край, тень скрепки и наклон папки 1°. Декоративное дело титула лежит в перспективе.

## Воспроизведение

Из корня проекта:

```powershell
python scripts/create-office-scene.py
python scripts/refine-portraits.py
python scripts/refine-level-icons.py
npm run build
node scripts/check-scene-budget.mjs
```

`refine-portraits.py` сначала пересоздаёт базовую пластину через `create-archive-assets.py`, затем наносит новую гравюру. Поэтому иконки уточняются последним шагом. Геометрия детерминирована, сетевые обращения отсутствуют.

## Движение и бюджет

В `OfficeScene.tsx` мышь двигает только декорации, максимум 6,81 px для ближайшего слоя. Текст и игровые документы не участвуют в параллаксе. Анимируются только transform/opacity: свет и пыль. При reduced-motion движения отключены, смещения сбрасываются; при скрытии страницы анимации приостанавливаются. Доступ к датчикам наклона не требуется.

Бюджет проверяется консервативно по всем файлам `public/assets`, включая отдельные дубликаты портретов. Результат и веса каждого файла — `docs/verification/etap0_6/scene-budget.json`. Дополнительно к SVG прибавляется весь скомпилированный JS/CSS приложения и service worker: даже эта консервативная сумма проверяется на лимит 400 000 байт. Там же проверяется присутствие всех ресурсов в сгенерированном офлайн-кеше. Растров нет.

Старые варианты A/C и исходные снимки этапа 0.5 сохранены только в истории Git и исторических материалах.
