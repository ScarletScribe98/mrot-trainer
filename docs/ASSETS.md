# Ассеты «Тёмного архива», этап 0.5

Созданы для проекта 17 ноября 2026 года. Все новые рисунки — оригинальные SVG, редактируемые текстом и повторно создаваемые `python scripts/create-archive-assets.py`. Скачанных изображений, фотографий, чужих логотипов и растровой генерации нет; промты генерации изображений не использовались.

## Инвентарь

Основной спрайт — `public/assets/archive.svg`, 20 символов. Его геометрия общая для трёх тем; окраска передаётся через CSS-переменные и currentColor. Компоненты — `src/ui/artwork.tsx`, оформление — `src/ui/assets.css`.

| Символ / файл | Что изображено | Где используется |
|---|---|---|
| `desk` | Направленный свет, плоскость стола, тень | Фон каждого экрана |
| `lamp` | Настольная лампа с металлической стойкой и стеклянным/эмалевым абажуром | Титульная композиция |
| `folder` | Тканевая папка, шов, клапан, две заклёпки | Титул и подложка карточки работника |
| `form` | Бланк с разлиновкой и регистрационными метками | Лист под титульным делом |
| `worker-card` | Служебная карточка с шестым портретом и полями | Титульная композиция |
| `clip` | Проволочная скрепка, два металлических блика | Титул и бланк работника |
| `stamp-frame` | Рамка «Проверка завершена» с потерями краски | Верный ответ, итог прохождения |
| `stamp-violation` | Прямоугольный вердикт с восклицательным знаком | После верного ответа с нарушением |
| `stamp-clear` | Прямоугольный вердикт с отметкой | После верного ответа без нарушения |
| `level-history` | Книга/хронология | Уровень 1 в каталоге |
| `level-map` | Складная карта с условной меткой | Уровень 2 в каталоге |
| `level-cards` | Три служебные карточки | Уровень 3 в каталоге |
| `level-ledger` | Расчётная ведомость | Уровень 4 в каталоге |
| `level-final` | Итоговый документ с отметкой | Финал в каталоге |
| `grain.svg` | Лёгкое печатное/плёночное зерно, тайл 96×96 | Фон рабочего стола и бумага |

Текст штампов, номера и ФИО набираются живым HTML, поэтому остаются чёткими, доступными для чтения и поиска. Вектор содержит рамку и фактуру отпечатка. Геометрические чёрный/белый внутри SVG-масок задают прозрачность, а не палитру темы.

## Цвет и движение

Тема A — холодный графит, тема B — бутылочный зелёный, тема C — тёплый серый. Цвет бумаги нейтральный; жёлтый маркер в C применяется только к формуле. Винный/красный цвет зарезервирован для вердикта и завершения проверки. Свет и зерно не мешают цифрам.

Микроанимации 150–400 мс и спокойное движение светового пятна определены в `src/ui/motion.css`; reduced-motion полностью отключает движение. Шрифты прежние, локальные OFL; сторонних ресурсов и пакетов для новых ассетов не добавлено. Права на оригинальные рисунки не ограничены сторонними лицензиями. Сторонние шрифты и зависимости перечислены в `CREDITS.md`.
