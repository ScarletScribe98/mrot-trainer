# Темы для выбора: этап 0.5

[Сводная картинка](compare.png) · [HTML для просмотра](compare.html) · [Шесть портретов и настройки](portraits-and-settings.png)

Во всех темах одни и те же учебные данные, разметка и правила игры. «Графит» — холодный монохром, «Зелёная лампа» — бутылочный зелёный и мягкий свет, «Нуар-редакция» — тёплый серый и крупный контрастный набор.

В каждой теме есть снимки точного окна 1920×1080 и 360×740, а также файлы `-full` с полной прокручиваемой страницей. На телефоне вопрос и штамп сняты с прокруткой к панели решения; карточка видна целиком в `-full`. Жёлтый маркер в теме C применяется только к базе в формуле, красный — только к вердикту и завершению.
