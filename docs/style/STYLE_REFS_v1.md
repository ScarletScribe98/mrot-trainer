## Синтез: единый стиль «Редакционный архив»

Не «кабинет сыщика из квеста», а тёмная витрина, в которую кладут настоящие дела. Тёмный хром приложения (сланец, охра, кремовая бумага) + живые документы поверх (бланки, папки, штампы, карта). Документ — главный объект. UI вокруг него тихий.

### Палитра (HEX, снято с референсов 2, 3, 7 и 8)

| Роль | HEX | Откуда логика |
|---|---|---|
| Фон приложения | `#0E1214` | почти чёрный с холодным подтоном, как поле Archivo / навигация Woodchipper, не коричневый «кабинет» |
| Панели, нижняя нав | `#1C2428` | семейство `#283038` / `#303840` с экранов Woodchipper |
| Приподнятые поверхности, герой истории | `#2F3C42` | сланец `#304048` |
| Приглушённый металл (подписи, линейки) | `#6A8288` | `#709098` / `#688890` |
| Охра — акцент системы (активный таб, XP, тонкие линейки, подзаголовки) | `#B09058` | панель профиля Woodchipper |
| Основной текст на тёмном | `#E8E4D8` | кремово-белый, не чистый `#FFFFFF` |
| Бумага документов | `#F1EBE0` | `#F0E8D8` / `#E8E8E0` |
| Папка (чистая манила, не грязная) | `#E4D3A8` | осветлённая родня охры |
| Чернила на бумаге | `#1A1A1A` | |
| Oxblood — штамп, ошибка, «Акт», статус «нарушение» | `#862226` | между `#982826` и `#742827` The Thing Is |
| Маркер / найденное / подсветка формулы | `#EEE142` | маркер на заголовке The Thing Is |
| Опциональный «точный» акцент на карте (не обязательный) | яркий оранжевый как в En Varslet Skandale, только точками, не заливкой | |

Правило: охра — системный цвет, oxblood — юридический вердикт, маркер — «смотри сюда». Одновременно все три почти не встречаются.

### Шрифты (Google Fonts, лицензия OFL, кириллица проверена по METADATA репозитория google/fonts)

Newsreader, который напрашивался по «газетности», в каталоге Google Fonts **не содержит кириллицу** (только latin / latin-ext / vietnamese) — его не берём.

1. **Source Serif 4** (OFL, есть `cyrillic` и `cyrillic-ext`) — заголовки уровней, имена на карточках, титул «Дело о минимальной зарплате», исторические плашки. Редакционный серif, не «готический костюм». Запасной вариант того же класса: Literata или Spectral (обе тоже OFL + кириллица).
2. **Golos Text** (OFL, `cyrillic` / `cyrillic-ext`, рисован под кириллицу) — интерфейс, кнопки, подсказки, сплошной текст разбора ошибки. Спокойный гротеск без «игровой» геометричности. Запасной: IBM Plex Sans (OFL, кириллица, более «ведомственный»).
3. **IBM Plex Mono** (OFL, `cyrillic` / `cyrillic-ext`) — номер дела, регион, даты, поля бланка, формула `B × (k + s)`, технические подписи вроде `ДЕЛО 014 / РЕГИОН / 2026`. Запасной: PT Mono или JetBrains Mono (оба OFL + кириллица).

Дополнительно, точечно: **Oswald** (OFL, кириллица) — узкие заголовки карты и штамп-слова вроде «НАРУШЕНИЕ», если Source Serif 4 в штампе будет слишком мягким. IBM Plex Sans Condensed не рекомендую: в METADATA указан только `cyrillic-ext`, без базового `cyrillic`.

### Композиция

- Тёмный кадр 16:9 как витрина; документ или карта — центр, не обои.
- Жёсткая сетка и много воздуха (Blood from Stone, Woodchipper): номер дела и тонкая линейка важнее рамки с вензелями.
- Стопка и сдвиг листов (Archivo, Papers Please, Case of the Dreamers) вместо плоских иконок папок.
- Карточка работника = бланк: фото, машинные поля, служебные коды, оборот или вкладка с расчётом.
- Карта регионов — контур + каталожная подпись, не «пин на пробковой доске с красной нитью», если только это не отдельный короткий жест.
- История МРОТ — крупная типографика и шкала/линейка, как в Woodchipper, а не комикс.
- Финальный акт — отдельный лист, который можно как бы вынуть и проштамповать.

### Фактуры

- Бумага: лёгкое зерно, кромка, иногда перфорация. Без грязных пятен «от кофе и пепла» на каждом экране.
- Документы могут быть цветными (разные типы бланков), сцена вокруг них — нет.
- Фото: зерно, дуотон, иногда угасание к краю. Не глянец стокового кадра.
- Штамп — краска, чуть неровная приводка, но один-два на лист.
- Карта — как подложка под бумагу или как тонкий контур, не игровое «королевство».

### Анимация и звук

- Бумага: короткий сдвиг, перелистывание, лёгкая тень при подъёме. Без пружинистого «мультяшного» отскока.
- Штамп: короткая пауза и прижим, не фейерверк.
- Разбор ошибки: маркер или красная линейка проводит по строке, затем рядом появляется шаг формулы.
- Переходы уровней — как смена листа в деле, не wipe «кино-нуар».
- В Woodchipper заявлен snap-scroll — нам скорее лёгкий snap секций, не длинный параллакс.
- Музыка и звуки тихие, с явным выключателем; выключатель лучше рисовать языком знака (п. 11), а не рычагом бомбы.

### Чего не делать (клише)

- Дама в шляпе, жалюзи, дым сигареты, штопор от пистолета, лупа как логотип.
- Капли крови, жёлтая лента CRIME SCENE, пробка с красной нитью как основной UI.
- Неон, киберпанк, glitch на каждом заголовке, кислотный «криминальный» красный.
- Казуальные бары энергии, монетки, глянцевые CTA, мультяшные персонажи.
- Советская / контрразведывательная эмблематика, игра в «СМЕРШ».
- Слишком грязная, нарочито «состаренная» бумага, на которой не читается цифра МРОТ.
- Шрифты без кириллицы (в том числе Newsreader из Google Fonts).
- Копирование макетов, текстов, фото и персонажей из референсов. Особенно не переносим содержание реальных уголовных дел.

## Промт для генерации макета (экран «Карточки работников», 16:9, русский интерфейс)

Готовый англоязычный промт. Цифры и фамилии на макете — временные, позже заменятся данными Эрики. Стиль — синтез выше, не копия ни одного референса.

```
A 16:9 UI mockup for an educational web trainer, one screen, Russian interface.

Product: “Инспектор труда: Дело о минимальной зарплате”, level “Карточки работников”.
Mood: stylish dark editorial archive, adult and precise, not a cartoon detective game and not film-noir costume cliché. Think a quiet museum vitrine for real case files: cool slate surroundings, living paper documents in the center.

Composition:
- Cinematic 16:9 desktop layout.
- Dark charcoal-slate application chrome around the edges.
```
