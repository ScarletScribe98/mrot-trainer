# Тренажёр «Инспектор труда»: техническая часть (черновик Кая v0, 17.11.2026)
Основа: TZ_Inspektor_truda_v1.md (Эрика). Это предложение для обсуждения с Артёмом, решений ещё нет.

## Стек (предложение)
- Статический сайт, без сервера и без сбора данных: Vite + TypeScript + Preact (компоненты, маленький вес). Альтернатива: чистый TS без фреймворка, проще, но экранов много, код быстрее расползётся.
- Расчётное ядро отдельным модулем `calc/`: B×(k+s), выбор применимого минимума, недоплата, округление по методичке v5. Покрыто тестами (Vitest), включая таблицу примеров от Эрики. Генерация задач с зерном (seed), чтобы любую задачу можно было воспроизвести при разборе ошибки.
- Данные уровней 1–2 (реальные цифры) в JSON, с полем-ссылкой на часть/пункт методички. Реальные регионы и вымышленные хранятся раздельно, смешать их генератор не может.
- Анимации: CSS-переходы + GSAP (бесплатная лицензия) для штампов, папок, перелистывания. Учитывать prefers-reduced-motion.
- Звук: Howler.js (MIT), музыка и эффекты с отдельными выключателями, по умолчанию музыка выключена (автовоспроизведение браузеры всё равно блокируют), громкость тихая.
- Прогресс: localStorage (XP, звания, достижения, «Личное дело»), кнопка «Начать заново».
- Адаптивность: телефон (вертикально) и проектор 16:9; крупный шрифт, контраст.

## Хостинг
- Основной: GitHub Pages из отдельного репозитория у Артёма, деплой GitHub Actions. Бесплатно, ссылка стабильная, QR на неё.
- Риск: доступность GitHub Pages из РФ/вуза не гарантирована навсегда. Запас: та же сборка на российском хостинге (статика, напр. на VDSINA через nginx — но это сервер бота, лучше отдельный дешёвый статический хостинг). Решить с Артёмом.
- QR: генерируется локально (например, пакет qrcode), PNG/SVG для методички. Короткий адрес лучше своего домена, без сервисов-сокращателей (могут умереть).

## Ассеты и лицензии
- Иллюстрации (папки, документы, штампы, фон архива, портреты вымышленных работников): генерация ИИ (я или Codex) в одном стиле по общему стилевому промту, затем ручной отбор; сохранять промты и даты в ASSETS.md. Для учебного проекта это допустимо; текст и цифры на картинках не генерировать — их накладываем вёрсткой.
- Шрифты: Google Fonts с кириллицей под лицензией OFL (напр. IBM Plex Sans/Serif, PT Serif, Golos Text) — подключать локально, не с CDN.
- Иконки: Lucide (ISC).
- Карта: стилизованная (10 регионов-плиток/карточек или упрощённый силуэт), чтобы не зависеть от лицензий картографических SVG. Если нужна настоящая карта — SVG с Wikimedia Commons (CC BY-SA, нужна атрибуция), проверить конкретный файл.
- Звуки: Kenney (CC0), Freesound только CC0. Музыка: CC0 или Pixabay Music (своя лицензия, без атрибуции) либо Kevin MacLeod (CC BY, нужна атрибуция). Сгенерированную ИИ-музыку не брать без проверки условий сервиса.
- Все источники и лицензии в CREDITS.md + экран «Об игре».

## Этапы для Codex (каждый — отдельный промт с критериями приёмки, проверяю я)
0. Каркас: Vite+TS+Preact, роутинг экранов, дизайн-система (цвета, шрифты, компоненты «папка», «документ», «штамп»), деплой-заглушка на Pages.
1. Расчётное ядро + генератор с seed + тесты (по примерам Эрики). Без UI.
2. Уровень 3 «Карточки работников» (основная механика) + подсказка/разбор + XP.
3. Уровень 4 «Аудит ведомости» (типы подложенных ошибок).
4. Финал «Дело № 001» + «Акт проверки» (печать/сохранение как изображение).
5. Уровни 1–2 на реальных данных из методички v5.
6. Звания, достижения, «Личное дело», «Срочная проверка», «Повторное расследование».
7. Ассеты, анимации, звук; проверка на телефоне и проекторе; QR и финальный деплой.
