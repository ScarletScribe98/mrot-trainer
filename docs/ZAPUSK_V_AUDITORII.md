# Запуск в аудитории

**Страница тренажёра после публикации** — [scarletscribe98.github.io/mrot-trainer/](https://scarletscribe98.github.io/mrot-trainer/). Адрес предварительный. Перед раздачей сверьте владельца репозитория и адрес в результате workflow **GitHub Pages**, затем проверьте переход по QR-коду с телефона.

![QR-код предварительного адреса тренажёра](pages-qr.svg)

1. Откройте тренажёр заранее на каждом устройстве. Дождитесь надписи «Архив доступен без интернета» внизу страницы. Откройте игру повторно без сети, чтобы проверить готовность.
2. На общих ПК перед новой группой откройте «Об игре» → «Начать заново» и подтвердите сброс. Опыт и результаты предыдущего игрока удалятся из этого браузера.
3. Если Pages недоступен, раздайте `work/mrot-trainer-dist.zip`. Чтобы подготовить архив, выполните `npm run build` с базой по умолчанию, затем `npm run pack`. Распакуйте его и запустите в папке с `index.html` команду `python -m http.server 8000 --bind 127.0.0.1`. Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/) в браузере. Такой сервер можно запустить на каждом ПК с Python 3.

Если итоговый адрес изменится, замените ссылку выше и перегенерируйте QR-код. Из корня проекта с установленным пакетом Python `qrcode` выполните команду, подставив адрес из workflow.

```sh
python -c "import sys, qrcode; from qrcode.image.svg import SvgPathFillImage; qrcode.make(sys.argv[1], image_factory=SvgPathFillImage).save('docs/pages-qr.svg')" "https://ВЛАДЕЛЕЦ.github.io/mrot-trainer/"
```
