# Инспектор труда — Тёмный архив

Этапы 0 и 0.5 по `docs/TZ_Codex_etap0.md` и `docs/TZ_Codex_etap0_5_stil.md`: локальный веб-тренажёр на Vite, TypeScript strict и Preact. Только уровень 3 играбелен. Данные вымышлены, реальные величины МРОТ не добавлены.

## Оформление

Единственная тема — «Зелёная лампа», выбранная Артёмом. Переключателя и выбора через URL больше нет. Старые ссылки с параметром theme открывают то же дело в единственном оформлении; параметр удаляется из адреса. Архив вариантов этапа 0.5 сохранён в истории Git и в прежних скриншотах.

## Запуск

Node.js 22.12+ (проверено на 24.19.0), npm. Все команды выполнять из папки проекта.

```powershell
npm ci
npm run dev
```

Открыть адрес из вывода Vite (обычно http://127.0.0.1:5173). Для собранной PWA:

```powershell
npm run build
npm test
npm run preview
```

Обычно preview доступен на http://127.0.0.1:4173. Не открывайте `dist/index.html` как файл. `npm test` выполняется один раз, без режима наблюдения. Кеш npm настроен в `.npm-cache` внутри проекта.

## Что можно проверить

Титул → «Открыть архив дел» → уровень 3 → пять карточек → результат. Остальные уровни и финал закрыты. На каждой карточке выберите вердикт; при нарушении введите недоплату в рублях. При первой ошибке появляется короткая подсказка, при второй — разбор без численного ответа. Штамп появляется только после верного ответа. Обновление страницы сохраняет опыт, этап прохождения, попытки, использованные подсказки и настройки.

Ссылка «Об игре» содержит объяснение демоданных и кнопку «Начать заново» с подтверждением удаления. «Новое учебное дело» после прохождения меняет seed и числа; накопленный опыт остаётся. Одна зачтённая карточка не начисляет опыт повторно при перезагрузке.

## Проверки и снимки

Для браузерных проверок нужен установленный Microsoft Edge. Глобальные пакеты и отдельный браузер не устанавливаются.

```powershell
$env:TEMP = Join-Path $PWD 'work/tmp'
$env:TMP = $env:TEMP
New-Item -ItemType Directory -Force $env:TEMP | Out-Null
npm run build
npm run test:browser
npm run audit
npm run licenses
```

`test:browser` поднимает локальный preview, проходит демо на 1920×1080 и 360×740, проверяет опыт, сохранение, сброс, повреждённое/заблокированное хранилище и работу без сети. Снимки находятся в `docs/screens`. Файлы без `-full` имеют точный размер окна, `-full` показывают всю прокручиваемую страницу. На телефоне карточка и форма идут последовательно; экраны с подсказкой и штампом сняты с прокруткой к соответствующему состоянию.

`audit` измеряет mobile Lighthouse на титуле и уровне 3 через локальный Edge. Полные HTML/JSON-отчёты и журналы команд — `docs/verification`. Это локальные измерения, они могут отличаться на другом компьютере.

## Архитектура

- `src/calc/`: чистые функции. Денежные аргументы и результат — целые копейки. Десятичные k и s хранятся строками, дробная арифметика выполняется через BigInt. Округление в одном месте — `roundMoney`, режим из `calculationConfig`.
- `src/calc/fixtures/method-v5.json`: пустая фикстура для будущих проверенных примеров Эрики.
- `src/game.ts`: состояние, зачёт, звания, валидация сохранений. `localStorage`, ключ `inspektor-truda-v1`, версия схемы 1. Повреждённое сохранение заменяется новым. При недоступности хранилища игра работает в памяти и сообщает об ограничении.
- `src/LevelThree.tsx`: пять карточек, решение, подсказки, разбор, результат.
- `src/ui/`: CSS-токены и повторно используемые компоненты папки, документа, штампа, кнопки, денежного ввода, подсказки, опыта, звуковых переключателей.
- `src/audio.ts`: тихие синтезированные эффекты и фоновый аккорд, без звуковых файлов. Музыка по умолчанию выключена; сохранённое включение возобновляется после жеста пользователя. Во время скрытия страницы музыка останавливается.
- `public/fonts/`: локальные WOFF2 с кириллицей и латиницей, рядом полные OFL-лицензии. Внешних запросов во время игры нет.

## Расчёт и согласованные правила наград

Расчёт: B × (k + s), база — большая из двух заданных. Недоплата — max(0, минимум − зарплата). До подтверждения методички v5 применяется округление до копеек, половина вверх: `TODO(Эрика)`.

Согласовано Артёмом в этапе 0.5: короткая автоматическая обратная связь после первой ошибки соответствует +70 при самостоятельном исправлении; явная подсказка по кнопке или развёрнутый разбор после повторной ошибки — +50. Первая попытка без подсказки — +100. Каждая неперекрывающаяся серия трёх карточек без ошибок и подсказок — ещё +50. Ошибка или раскрытая подсказка прерывает серию. В пяти карточках доступна одна такая премия. Награда +150 за все уровни не включена, поскольку этап 0 не содержит всей игры.

Согласованные пороги званий: 0 / 300 / 800 / 1500 очков. Численные ответы не показываются ни в первой подсказке, ни в разборе. Буквы N и X в ссылке на методичку — прямо требуемая ТЗ заглушка, рядом `TODO(Эрика)`.

## PWA и публикация после проверки

В production сборке service worker предварительно сохраняет HTML, JS, CSS, локальные шрифты и иконки. Дождитесь подписи «Архив доступен без интернета», затем можно отключать сеть и обновлять страницу. В режиме dev service worker не включён. Обновление установленной версии активируется после закрытия вкладок старой версии и следующего открытия; без принудительной перезагрузки во время решения. Первый запуск без сети невозможен.

`vite.config.ts` использует относительный base `./` по умолчанию, переопределяемый через `BASE_PATH`. Hash-навигация не требует серверных правил перенаправления. Поддерживается подпапка репозитория.

`.github/workflows/deploy.yml` подготовлен, но запускается **только вручную** через `workflow_dispatch`. После отдельного решения о публикации понадобится создать репозиторий, отправить код и включить Settings → Pages → GitHub Actions. Workflow сам выбирает `/<имя-репозитория>/`, а для `<владелец>.github.io` — `/`. Деплой в этой работе не выполнялся.

## Ограничения

Нет реальных юридически значимых данных и проверенных примеров методички, уровней 1/2/4, итогового акта всей игры, достижений или серверного хранения. Это границы этапа 0. Визуальные референсы из `docs/style` не включаются в сборку; картинки третьих лиц используются только как ориентиры, не как игровые ресурсы.
